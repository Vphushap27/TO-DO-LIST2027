Pro Task Manager ⚡
​A modern, responsive, and aesthetic To-Do List web application featuring a sleek Glassmorphism UI, Dark Mode Aesthetics, and real-time task tracking capabilities. Built using vanilla HTML5, CSS3, and JavaScript with Local Storage support.
​🚀 Live Demo
​Check out the live application here:
👉 https://vphushap27.github.io/TO-DO-LIST2027/
​✨ Features
​Glassmorphism UI: Ultra-modern translucent card design with smooth gradient lighting and background blobs.
​Task Counter: Live tracking of Total, Pending, and Completed tasks.
​Local Storage Integration: Automatically saves your tasks in the browser so your data remains intact upon page refresh.
​Filter Options: Easily switch views between All, Active, and Completed tasks.
​Mobile Responsive: Fully optimized for all mobile screens, tablets, and desktops.
​🛠️ Tech Stack
​HTML5 - Structured document markup
​CSS3 - Glassmorphism, CSS variables, flexbox, blur effects, and animations
​JavaScript (ES6+) - Dynamic DOM manipulation, state management, and localStorage API
​📝 How to Use
​Add Task: Enter your task details in the input box and tap Add.
​Complete Task: Tap/click directly on any task item to toggle its completed state (strike-through effect).
​Filter Tasks: Tap All, Active, or Completed to filter your list view.
​Delete Task: Tap the red Delete button next to any task to remove it permanently.
